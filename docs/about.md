# About

site-preflight is built and maintained by DigitalCave, an all-in-one web design, SEO and digital
marketing agency in the West Midlands. We wrote it as the checklist we wanted to run on every
site before handing it over to a client, and released it so anyone can use it.

The tool's home page, with background on why it exists and the faults it catches, is at
[digitalcave.uk/tools/site-preflight](https://digitalcave.uk/tools/site-preflight).

If you would rather have a site built and checked properly from the start, our
[web design team in Birmingham](https://digitalcave.uk/web-design-service-birmingham) can help.

## Source and downloads

- Source code, issues and releases: [github.com/digitalcaveuk/site-preflight](https://github.com/digitalcaveuk/site-preflight)
- Docker image: [hub.docker.com/r/digitalcave/site-preflight](https://hub.docker.com/r/digitalcave/site-preflight)

## Contributing

Bug reports and pull requests are welcome on
[GitHub](https://github.com/digitalcaveuk/site-preflight/issues). Please keep the tool small:
standard library only, one command, a readable report. Run the tests before opening a pull
request:

```sh
python3 -m unittest discover -s tests -v
```
